# chromebook-keyboard-backlight

A simple bash script that allows you to enable the backlight of your external keyboard on Chromebook

## Requirements
- Chromebook with Developer Mode turned on
- Access to VT2 shell

> For some newer Chromebook, you need to enable *Debugging Features* and set the password on setup screen the first time you enabled the Developer Mode in order to access VT2 shell

## How to use
1. Switch to VT2 shell (`Ctrl` + `Alt` + `Forward` or `F2`)
2. Login as `root` and put your password
3. Download this script using `curl`
4. Run it: `bash main.sh`
